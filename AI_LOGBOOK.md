Deskripsi Proyek:
EduPlay Arena merupakan situs web yang dirancang sebagai media ice breaking edukatif untuk kegiatan belajar mengajar. Situs ini menyediakan empat permainan interaktif yang menggabungkan unsur pembelajaran dan hiburan. Tower of Quiz mengajak pemain menjawab soal untuk memperoleh poin lompatan dan mencapai puncak menara. Cyber Maze Race menguji kecepatan pemain melewati labirin dengan menjawab kuis. Galaxy Tug-of-War merupakan permainan adu kekuatan antartim dengan menjawab soal untuk menarik Quantum Core. Neon Fish Raid mengajak pemain bekerja sama menangkap ikan neon dan mengalahkan boss melalui jawaban kuis.

Tahap 1 — Eksplorasi Ide dan Perancangan Solusi
Kami merancang EduPlay Arena sebagai portal permainan edukatif yang menyediakan empat game ice breaking dengan mekanisme berbeda, yaitu Tower of Quiz, Cyber Maze Race, Galaxy Tug-of-War, dan Neon Fish Raid. Setiap permainan memiliki mode guru, mode siswa, dan mode uji coba solo.
Prompt AI:
Saya ingin membuat situs web ice breaking edukatif dengan empat game: Tower of Quiz, Cyber Maze Race, Galaxy Tug-of-War, dan Neon Fish Raid. Setiap game memiliki mekanisme berbeda, fitur multiplayer menggunakan kode ruangan, pengaturan kuis oleh guru, leaderboard, dan mode solo. Bantu susun rancangan fitur dan alur programnya.
Hasil AI: AI memberikan saran mengenai struktur portal, mekanisme setiap game, pengaturan ruang permainan, sistem kuis, serta interaksi guru dan siswa.

Tahap 2 — Penyusunan Kerangka Kode
Kami menyusun program menggunakan HTML, CSS, dan JavaScript. Program dibagi menjadi halaman portal, dashboard guru, tampilan siswa, serta mekanisme permainan.
Prompt AI:
Bantu susun kode JavaScript untuk empat game EduPlay Arena. Tower of Quiz menggunakan poin lompatan, Cyber Maze Race menggunakan turbo untuk membuka gerbang, Galaxy Tug-of-War menggunakan daya traktor untuk menarik inti kuantum, dan Neon Fish Raid menggunakan serangan ikan untuk mengurangi HP boss. Sesuaikan logika dengan fitur multiplayer dan mode solo.

Tahap 3 — Pemecahan Masalah dan Penanganan Galat
Kami menguji fitur permainan, seperti koneksi multiplayer, kode ruangan, timer, pergerakan pemain, sistem reward, dan pembaruan skor. AI membantu mengidentifikasi kemungkinan kesalahan serta memberikan alternatif perbaikan.
Prompt AI:
Bantu periksa kemungkinan kesalahan pada program EduPlay Arena, terutama koneksi multiplayer menggunakan MQTT, kode ruangan, timer guru, leaderboard, serta mekanisme reward pada keempat game. Berikan saran perbaikan agar fitur dapat berjalan dengan baik.
Hasil AI: AI menyarankan pemeriksaan koneksi, validasi kode ruangan, pembaruan data pemain, kondisi jawaban, serta fungsi permainan agar tidak terjadi kesalahan saat program dijalankan.

Tahap 4 — Refleksi dan Penjelasan Kode
EduPlay Arena menggunakan HTML untuk struktur halaman, CSS dan Tailwind CSS untuk tampilan, serta JavaScript untuk mengatur logika permainan. Kode membantu siswa bergabung ke ruang permainan.
Melalui proyek ini, kami belajar membuat portal permainan interaktif, menghubungkan fitur kuis dengan mekanisme game, serta melakukan pengujian dan perbaikan program. AI membantu dalam memahami kode dan mencari solusi, sedangkan pengembangan dan penyesuaian dilakukan berdasarkan kebutuhan proyek.
Refleksi: Kami memperoleh pengalaman dalam mengembangkan produk digital berbasis koding dan memanfaatkan AI sebagai pendamping untuk eksplorasi ide, pemahaman kode, serta pemecahan masalah.
